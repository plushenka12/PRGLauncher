# P1 UX checklist

Ручна перевірка перед наступним релізом. Запускати через `npm run dev`.

## Головний екран

- [ ] На 90%, 100% і 120% картки мають однакову висоту; текст не налазить на кнопки.
- [ ] Hover і keyboard focus не рухають сітку та не змінюють висоту картки.
- [ ] Кнопки `Playing`, `Backlog`, `Completed`, `QuickPlay` і фільтри мають однаковий шрифт і контраст.
- [ ] На широкому вікні працює щільна сітка, на вузькому — без горизонтального скролу.

## Recap

- [ ] Перемикання року оновлює всі показники та графіки.
- [ ] Клік по місяцю показує його деталі; найактивніший місяць виділений.
- [ ] Відображаються гра року, топ за часом, найдовша сесія та платформи.
- [ ] Клік/Enter по картці гри року відкриває `Game Info`.
- [ ] PNG/share-експорт не обрізає обкладинки та текст.

## Локальні ігри

- [ ] У редагуванні можна змінити executable, working directory та launch arguments.
- [ ] Повторний вибір executable оновлює шлях і запускає гру з правильним cwd/аргументами.

## Стани інтеграцій

- [ ] RAWG: loading, порожній результат і network error мають зрозумілий текст.
- [ ] Steam Downloads: loading/error/empty не залишають завислий спінер.
- [ ] Nintendo: порожня історія показує empty-state, а не порожній блок.
- [ ] HLTB: unavailable показує fallback; збережені дані гри не зникають.
- [ ] Системні іконки мають tooltip/accessible label.
