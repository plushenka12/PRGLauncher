# PRG 3DS

Homebrew для Nintendo 3DS із Luma3DS. Він надсилає час гри з консолі в PRGLauncher через домашню мережу.

Програма лише читає журнал активності консолі і нічого на консолі не змінює. Журнал (`PlayHistory.dat` у системному сейві PTM `0x00010022`) читається через сервіс `ptm:play`, бо сам файл тримає відкритим PTM. Пряме читання файлу лишилось запасним варіантом. Разом із журналом вона надсилає назви встановлених ігор. Сесії з журналу рахує сам лаунчер (`src/main/n3ds-history.js`), тому цю логіку покривають тести на ПК.

## Встановлення

1. Скопіюй `prg3ds.3dsx` у папку `/3ds/` на SD-картці.
2. У PRGLauncher відкрий «Налаштування → Інтеграції → Nintendo 3DS» і ввімкни «Приймати дані з 3DS».
3. На 3DS відкрий Homebrew Launcher (Rosalina: L + ↓ + Select → Miscellaneous options → Switch the hb. title to the current app, або будь-яким звичним способом) і запусти PRG 3DS.
4. Натисни X і введи адресу ПК, порт і 6-значний код, які показує лаунчер. Налаштування зберігаються в `sdmc:/3ds/PRG3DS/config.txt`.
5. Натисни A. Після відповіді «Done» сесії з'являться в лаунчері.

Повторне надсилання сесії не дублює. Ігри без назви на консолі (видалені, DSiWare, картриджі DS) поки пропускаються.

## Збірка

Потрібен devkitARM із libctru. Найпростіше зібрати в Docker:

```bash
docker run --rm -v "$PWD:/src" -w /src devkitpro/devkitarm make
```

Результат: `prg3ds.3dsx` і `prg3ds.smdh` поруч із `Makefile`.
