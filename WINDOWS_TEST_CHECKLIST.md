# PRGLauncher — Windows test checklist

## Release and account

- [ ] Чиста установка `1.2.2` через NSIS-інсталятор.
- [ ] Ярлик Desktop/Start Menu має назву PRGLauncher і зелено-фіолетовий клевер.
- [ ] Процес у Task Manager називається PRGLauncher.
- [ ] Автозапуск стартує тихо в tray; звичайний ярлик відкриває головне вікно.
- [ ] Вхід, вихід і повторний вхід через Email/Password та Google.
- [ ] Два PRG Account на одному ПК не змішують бібліотеки.
- [ ] Запуск без мережі показує локальні дані, а після появи мережі синхронізується.

## Library and cards

- [ ] Картки однакового розміру, назва максимум у два рядки, hover не рухає grid.
- [ ] На обкладинці видно статус, таймер, платформу та кількість сесій без дублювання при hover.
- [ ] Playing / Backlog / Completed / Quick Play та Filters мають однаковий шрифт.
- [ ] Натискання статусу на картці й у Game Info відкриває швидку зміну.
- [ ] Старт Backlog-гри переводить її у Playing.
- [ ] Edit Game → Save повертає у Game Info тієї самої гри.
- [ ] HLTB відкривається, кешується, дозволяє змінити match і сховати блок.

## Steam

- [ ] Імпорт профілю показує назви, обкладинки, пошук, «Обрати всі» та статуси.
- [ ] Імпорт встановлених ігор не створює дублікати.
- [ ] `BACKLOG` baseline не тягне старі записи; нові записи з’являються один раз.
- [ ] Встановлена гра запускається одразу через Steam.
- [ ] Невстановлена гра відкриває вибір бібліотеки Steam, і це вікно не зникає.
- [ ] Після вибору диска Downloads показує прогрес, після скасування показує скасування.
- [ ] Steam ховається тільки після фактичного старту завантаження.
- [ ] Ручне відкриття Steam із tray не ховається лаунчером.
- [ ] Автоматична Steam-сесія стартує лише для реально запущеної гри.

## GOG local MVP

- [ ] Settings → Integrations → «Імпорт встановлених GOG-ігор» знаходить GOG-ігри.
- [ ] Працюють GOG Galaxy у 32/64-bit варіантах і бібліотека на іншому диску.
- [ ] Імпорт показує шлях, дає пошук, масовий вибір і статус для кожної гри.
- [ ] Повторний імпорт не створює дублікати та зберігає `sources[]`.
- [ ] GOG-гра запускається локальним executable; fallback через GOG protocol не ламає лаунчер.
- [ ] Відсутній executable показує зрозумілу помилку, а не завершує застосунок.
- [ ] GOG не просить пароль і не записує cookies або токени.

## Nintendo, recap and updater

- [ ] Nintendo OAuth, ручний sync, delta-time та ігнорування записів працюють.
- [ ] Нова Nintendo-сесія показується при відкритті головного вікна, не в tray.
- [ ] Recap оновлюється після зміни даних і правильно фільтрує рік.
- [ ] Кнопка «Звіт» відкриває персональний dashboard.
- [ ] Check for updates знаходить `1.2.2`, а autoUpdater завантажує й встановлює реліз.
