# PRGLauncher macOS — інструкція для тестувальника

Дякую за тест. Це тестова, **непідписана** збірка PRGLauncher для macOS. Вона не має доступу до чужих даних: бібліотека прив'язується до того PRG Account, у який ти ввійдеш.

## 1. Отримай окремий macOS-білд

1. Відкрий GitHub-репозиторій PRGLauncher → вкладку **Actions**.
2. У лівому списку обери **Build macOS test package**.
3. Відкрий найновіший успішний запуск і внизу, в секції **Artifacts**, завантаж `PRGLauncher-macOS-universal-test`.
4. Розпакуй ZIP. Усередині буде `PRGLauncher-<версія>-universal.dmg`.

Цей один `.dmg` працює і на Intel Mac, і на Mac з Apple Silicon (M1/M2/M3/M4).

## 2. Встановлення

1. Відкрий `.dmg` подвійним натисканням.
2. Перетягни **PRGLauncher.app** у папку **Applications** у вікні інсталятора.
3. Відкрий папку Applications.
4. Натисни на PRGLauncher правою кнопкою / Control-клік → **Open** → ще раз **Open**.

Якщо macOS показує лише **Done** та **Move to Bin** і не дає кнопки Open:

1. Закрий це повідомлення через **Done**.
2. Одразу відкрий **Apple menu → System Settings → Privacy & Security**.
3. Прокрути до блоку **Security** і натисни **Open Anyway** біля повідомлення про PRGLauncher.
4. Підтверди дію паролем Mac і в наступному діалозі натисни **Open**.

Кнопка **Open Anyway** доступна приблизно годину після невдалої спроби запуску. Попередження очікуване: тестова збірка ще не має фінальних Apple code signing і notarization. Не вимикай Gatekeeper глобально та не вводь Terminal-команди для зняття захисту — це разовий дозвіл тільки для PRGLauncher, який тестер отримав із офіційного GitHub-білду.

## 3. Важливо про акаунт і дані

- Створи окремий тестовий PRG Account або використовуй власний, але **не** чужий акаунт.
- Не підключай Nintendo Account іншої людини.
- Якщо перевіряєш Steam-імпорт, використовуй свій Steam-профіль. Посилання на профіль читає лише публічну бібліотеку Steam.
- Тестові ігри, статуси й сесії синхронізуються у Firebase для твого PRG Account та можуть з'явитися на твоїй сторінці статистики.

## 4. Чекліст тестування

Познач біля кожного пункту: ✅ працює / ⚠️ проблема / ➖ не тестував.

### Запуск та інтерфейс

- [ ] PRGLauncher відкривається без чорного екрана або помилки.
- [ ] Вхід / створення PRG Account працює; після входу не видно чужих ігор.
- [ ] Зелено-фіолетовий клевер видно в Dock і у верхньому меню macOS.
- [ ] Нативні кнопки macOS зліва зверху (червона, жовта, зелена) працюють.
- [ ] Після закриття червоною кнопкою застосунок ховається, але лишається доступним через іконку у верхньому меню.
- [ ] У Settings одразу є фокус, вікно не відкривається нижче екрана.
- [ ] Українська / English, теми та масштаб 90–120% застосовуються одразу.
- [ ] Підказки з'являються при наведенні на іконки.

### Бібліотека та Steam

- [ ] Вставлення посилання на Steam-профіль повертає картки з обкладинками.
- [ ] Пошук, «Обрати всі», «Зняти вибір» та додавання вибраних ігор працюють.
- [ ] Клік по статусу гри змінює Backlog / Playing / Completed.
- [ ] Ручний таймер додає сесію та переводить Backlog-гру в Playing.
- [ ] Якщо Steam встановлений: клік Launch / Install відкриває правильну гру або її сторінку у Steam.

На macOS автоматичне визначення уже запущеної Steam-гри не тестується — воно свідомо вимкнене, бо система не має стабільного API без додаткових небезпечних дозволів.

### Mini-bar, tray і статистика

- [ ] Mini-bar відкривається плавно, стає у правому верхньому куті та лишається поверх вікон.
- [ ] Pin, Stand By, повернення до головного вікна та завершення сесії працюють.
- [ ] Іконка в верхньому меню macOS відкриває PRGLauncher подвійним натисканням; Quit повністю завершує його.
- [ ] Сторінка статистики в браузері показує дані поточного PRG Account.

### Nintendo Sync (лише за бажанням)

- [ ] Вікно Nintendo авторизації відкривається та закривається коректно.
- [ ] Після імпорту картки мають назви, обкладинки та час.

## 5. Як описати проблему

Надішли власнику PRGLauncher одне повідомлення у такому вигляді:

```text
Mac: [модель] / [Intel або Apple Silicon] / macOS [версія]
PRGLauncher: [версія з назви DMG]
Пункт чекліста: [назва]
Що зробив: [точні кроки]
Що очікував: [...]
Що сталося: [...]
Скріншот або короткий запис екрана: [додати]
```

Для проблем із вікном, tray або mini-bar обов'язково додай скріншот усього екрана, щоб було видно верхнє меню macOS.
