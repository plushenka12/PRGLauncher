# RAWG proxy для Windows-лаунчера

Стан: обидві змінні Netlify environment присутні; production deploy і пошук із власним акаунтом ще треба перевірити. Не вважати RAWG-пошук готовим на іншому ПК, доки не пройде перевірка нижче.

Лаунчер відправляє пошуковий запит із Firebase ID token через вузький Electron IPC до `/.netlify/functions/rawg-search`. Функція перевіряє owner UID і тільки тоді звертається до RAWG. Ключ RAWG не має потрапляти до renderer, інсталятора, Git чи відповідей функції.

## Перед пушем клієнтського коду

1. Створи **новий** RAWG API key у своєму RAWG-акаунті. Старий ключ уже був у публічному клієнтському коді; перенесення його в Netlify не зробить його знову приватним. Не надсилай ключ у чат і не записуй у файли репозиторію.
2. У Netlify → Site configuration → Environment variables додай `RAWG_API_KEY` і `FIREBASE_WEB_API_KEY` зі scope для Functions / production. Firebase Web API identifier можна взяти з Firebase project settings; це не service-account credential. Не встановлюй змінні через GitHub Actions logs або публічні файли.
3. Переконайся, що Netlify Git integration деплоїть корінь репозиторію з `netlify.toml`, а не тільки папку `web-dashboard`. Функція має відповідати на POST `/.netlify/functions/rawg-search`.
4. Після деплою перевір: без токена → `401`; із чужим Firebase UID → `403`; з власним UID пошук повертає результати й обкладинки; запит із некоректною довжиною/розміром сторінки → `400`. Не публікуй токени в issue, логах або документації.
5. Лише після успішного owner-запиту онови dev-лаунчер і перевір ручне додавання гри, пошук нестандартної назви, оновлення обкладинок та прихованих тегів. Якщо проксі не налаштовано, RAWG показуватиме недоступність, але наявна бібліотека лишиться локально й у Firebase.
6. Відклич старий RAWG key у RAWG після переходу на новий. Старі коміти не можна вважати безпечним місцем для ключів.

Автоматичний локальний тест без справжніх ключів: `node --test tests/rawg-proxy.test.cjs`. Він перевіряє валідацію, owner-only доступ і форму відповіді, але не замінює production smoke-тест.
