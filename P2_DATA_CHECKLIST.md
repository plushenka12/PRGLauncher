# P2 data integrity checklist

Досягнення навмисно не входять у P2.

## Sync

- [ ] Запустити PRGLauncher без мережі, створити/змінити сесію, повернути мережу та перевірити автоматичний retry.
- [ ] Переконатися, що повторна доставка тієї самої сесії не створює дублікати.
- [ ] Змінити дані на іншому клієнті під час локальної зміни й перевірити явне sync-conflict вікно.
- [ ] Перевірити, що локальна офлайн-сесія не зникає після отримання новішого snapshot.

## Backup та приватність

- [ ] Export JSON → Import JSON на тестовому акаунті: ігри, сесії, тема та ігноровані Nintendo IDs відновлюються.
- [ ] Перевірити пошкоджений/дубльований backup — імпорт має бути відхилений.
- [ ] Export diagnostics не містить нотаток, токенів, Steam ID або повної бібліотеки.
- [ ] Очистити локальні дані та переконатися, що хмарні залишилися.
- [ ] Видалити хмарні дані й переконатися, що очищено також публічний Recap.
